HOW TO USE

Frame Reader

Use the frame dropdown to move anywhere in the novel. New frame opens start at the frame heading unless you intentionally use a return or resume action.

Frame Start

The floating frame button always returns you to the current frame heading, even if your saved reading spot is lower on the page.

Return To Latest Page

The homepage novel popup can send you back to your saved frame and reading position across the whole reader.

Lore Tags

Clickable names and world terms open quick-reference entries. Turn Lore Tags off in FEATS if you want plain text without highlighted terms.

Display Controls

Theme, font, spacing, alignment, and focus settings are saved locally on this device for the reader.

Popup Behavior

Reader panels open as overlays. Background scrolling is locked while a popup is open so the page underneath stays in place.

Read Along

The Read Along switch in FEATS controls whether the top audio buttons are shown. Turning it off hides the TTS controls and stops active speech.

Voice & Tempo

Choose a browser voice and test it in Settings. Tempo changes how quickly each frame is read.

Saved Audio Spot

TTS remembers its place per frame, so pausing one frame does not overwrite the saved spoken spot for another.

Downloads

Export the novel to EPUB, PDF, TXT, or HTML from the download button in the top bar.

Clear Novel Data

The homepage novel popup asks for confirmation before clearing saved frame position, TTS progress, comments, and reader-specific local data.

Master Reset

The trash button in panel headers restores reader settings to defaults for this device.
